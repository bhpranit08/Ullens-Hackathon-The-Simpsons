# TrailGuard mobile and web

See the [project README](../README.md) for complete local setup, two-account walkthrough, Expo development builds, tracking permissions, provider configuration, and verification commands.

Routes live in `src/app`. Shared code lives in `src/components`, `src/hooks`, and `src/lib`. Native/web tracking and maps use platform-specific implementations.

Run `npm run web` for the browser. Real background tracking and push notifications require a native development build, not Expo Go.
